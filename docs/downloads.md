# Suggested Downloads

## Essential Tools

- A TeX distribution with `xelatex` and `latexmk`: TeX Live or MiKTeX
- Pandoc for document conversion and quick format changes
- Zotero or JabRef for paper, citation, and bibliography management
- draw.io Desktop for workflow charts and model diagrams
- Git for version control and submission packaging

## Useful Optional Tools

- GeoGebra for geometry and quick visual reasoning
- QGIS for geographic or spatial questions
- Graphviz when the problem needs graph diagrams
- R and RStudio when you want a second statistics toolchain
- Gurobi or CPLEX academic licenses for larger optimization models
- Typst if you want a lighter backup report workflow outside LaTeX

## Suggested Reference and Data Sources

- National and regional statistical yearbooks
- Weather data portals such as CMA or NOAA
- Kaggle for public datasets and baseline ideas
- OpenStreetMap or AMap style map data for routing questions
- Research papers from CNKI, Google Scholar, or school library databases

Download only what matches the current problem type. Keep the core environment small and add heavy solvers only when a model really needs them.
