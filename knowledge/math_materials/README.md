# 数学建模资料 Knowledge

本目录用于存放来自外部资料包“数学建模资料”的结构化整理结果，目标不是简单备份原文件，而是把适合后续 AI 检索、写作和提示工程复用的内容沉淀下来。

## 当前内容

- `materials_inventory.md`: 对外部资料包根目录与候选资料的清单化汇总
- `materials_catalog.json`: 自动生成的全量文件编目，含来源压缩包和候选标签
- `materials_excerpts.json`: 自动抽取的 PDF 前几页文本片段
- `selected_source_excerpts.md`: 代表性手册与优秀论文的证据片段
- `excellent_papers_index.md`: 明确属于优秀论文集或手册内含优秀论文的资料索引
- `ai_reading_schema.json`: 面向 AI 阅读与写作辅助的标准化切片 schema

## 资料归类结论

1. 明确的优秀论文集合主要集中在“国赛优秀论文集”“美赛特等奖论文集”“华数杯-C题-优秀论文”“历届小美赛优秀论文汇总”“数维杯国际赛真题及优秀论文集”等压缩包中。
2. 规范性资料主要来自“参赛手册”“报名通知”“竞赛章程”“参赛规则”类 PDF，这些文件更适合提取格式要求、投稿流程和赛事约束。
3. 写作层面最稳定的可复用信息来自两类证据：
   - 手册中的“规则/提交流程/论文格式规范”
   - 优秀论文中的“摘要写法/问题分析/模型结构/结果解释/模型评价”

## 已识别的重要现象

1. 中文竞赛优秀论文普遍采用“摘要中按问题逐条概述方法与结论”的写法。
2. 高质量论文通常在“问题重述”和“问题分析”之间做一次任务拆解，明确每问对应的方法选择理由。
3. 优秀论文比普通论文更强调“模型检验、结果评估、优缺点与推广性”，而不仅仅是给出结果。
4. 国际赛或英文赛材料更强调匿名页、承诺书、题号页、Summary Sheet/Abstract 等固定前置部分。

## 使用建议

1. 先读 `excellent_papers_index.md` 选定参考风格，再读 `ai_reading_schema.json` 直接提取写作模板和风格规则。
2. 若后续继续补充外部资料，只需重新运行 `scripts/knowledge/catalog_math_materials.py` 更新清单与片段。
